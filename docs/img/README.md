# Capturas de tela

Salve aqui as imagens usadas na documentação:

- `dashboard.png` — visão geral do dashboard **Purple Honeypot SIEM**, com os cinco painéis e dados reais.
- `telegram-alert.png` — mensagem real recebida no Telegram, com regra, nível, IP, usuário e ação sugerida.

Recomendações:

- use PNG com largura entre 1200 e 1600 px;
- oculte tokens, chat IDs, IPs pessoais e qualquer dado sensível antes de publicar;
- mantenha o tema escuro ou claro consistente com o restante das capturas.

Depois de adicionar os arquivos, inclua as imagens no `README.md` quando a seção de demonstração visual for criada.
